# 韩佳浩 · 每日工作台（GitHub Pages 版）

纯静态单文件工作台，数据保存在浏览器 localStorage（无需后端服务器）。

## 包含的模块
- 每日任务
- 英语学习（打卡日历）
- 健身（训练日历）
- 睡眠（作息日历）
- 工作（求职追踪）
- 记账（收支日历）

## 本地预览
直接用浏览器打开 `index.html` 即可。

## 部署到 GitHub Pages
1. 在 GitHub 新建一个仓库（例如 `workbench`）。
2. 把本仓库内容推送到 `main` 分支。
3. 仓库 Settings → Pages → Source 选 `main` 分支、根目录 `/`，保存。
4. 几分钟后访问 `https://<你的用户名>.github.io/<仓库名>/`。

> 注：数据仅存在你打开页面的那台设备/浏览器里。换手机或清缓存会丢失，建议重要内容自行备份。
